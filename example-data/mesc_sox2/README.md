# mESC Sox2 FISH Data with Missing Coordinates

## Overview

Small test dataset extracted from Huang et al. (2021) mESC Sox2 5kb resolution chromatin tracing data.

- **Source**: Huang et al. (2021) *Nature Genetics* "High-resolution multi-omics sequencing of single cells" 
  https://doi.org/10.1038/s41588-021-00863-6
- **Species**: Mouse embryonic stem cells (mESC)
- **Locus**: Sox2 region
- **Resolution**: 5kb

## Files

### Small Test Set (for tutorial)

- `mESC_Sox2_5cells_wnan.h5cd` (17 KB)
  - **Format**: ChromData HDF5
  - **Content**: 5 cells × 82 loci = 410 spots
  - **Missing rate**: ~30%
  - **Purpose**: Tutorial demonstration, unit testing

- `mESC_Sox2_5cells_wnan.txt` (25 KB)
  - **Format**: SnapFISH format (tab-separated)
  - **Columns**: region, haploid, pos, x, y, z
  - **Purpose**: Format conversion example

- `mESC_Sox2_ann_chr129.txt` (2 KB)
  - **Format**: Annotation file
  - **Columns**: region, pos, start, end
  - **Purpose**: Genomic coordinates for region 129

### Imputed Results (generated by tutorial)

- `mESC_Sox2_5cells_imputed_linear.h5cd`
  - Linear interpolation result
  - Missing rate: 0%

- `mESC_Sox2_5cells_imputed_snapfish.h5cd` (optional)
  - SnapFISH-IMPUTE result
  - Missing rate: 0%
  - Requires sklearn, skimage

## Usage

### Load in Python

```python
import uchrom as uc

# Load data with missing coordinates
cd = uc.ChromData.read('example-data/mesc_sox2/mESC_Sox2_5cells_wnan.h5cd')

# Impute missing coordinates
from uchrom.im.impute import impute_coordinates
cd_imputed = impute_coordinates(cd, method='linear')

# Save result
cd_imputed.write('example-data/mesc_sox2/mESC_Sox2_5cells_imputed.h5cd')
```
