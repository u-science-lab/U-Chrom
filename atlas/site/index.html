Browse 3-D genome datasets without downloading them

Spatial Hi-C, Hi-C-RNA and ATAC-Hi-C sections, with per-spot contact maps, A/B compartments, RNA and tissue images, stored in the ChromData format and read over HTTP on demand: opening a dataset fetches a few megabytes, not the whole store.

Open a dataset in U-Chrom

The interactive browser runs on your machine and reads the data straight from this atlas.

  1. Install U-Chrom:
  2. Start the browser: python -m uchrom.browser --web
  3. Click Open in U-Chrom on a dataset below, or open the Atlas panel in the browser's Open dataset dialog.
