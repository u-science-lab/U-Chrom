U-Chrom Atlas

Built with U-Chrom, software for chromatin 3-D structure (source code coming soon). Every dataset is one ChromData store, read on demand or downloaded as a single .cdz file.

The data belong to the authors of each study; see the study for its source and licence. Contact maps marked reprocessed were rebuilt by U-Chrom from the deposited read pairs.
