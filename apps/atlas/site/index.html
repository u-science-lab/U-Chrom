LOCAL CONTINUATION

Continue locally

Atlas prepares a local browser command and an instruction for your already-configured Claude Code or Codex U-Chrom MCP. This dialog is built in your browser from the catalog URL; it creates no handoff token, sends no handoff API request, and does not probe localhost.

Prerequisite: the browser and agent packages are source-only (not on PyPI). From a U-Chrom checkout, install all three packages before starting the local page: uv pip install -e packages/chromdata -e packages/uchrom-browser -e packages/uchrom-agent.

Run the install command once, run the launch command each time, wait for the page to open, then paste the MCP instruction.
U-Chrom Atlas

Built with U-Chrom, software for chromatin 3-D structure (source code coming soon). Every dataset is one ChromData store, read on demand or downloaded as a single .cdz file.

The data belong to the authors of each study; see the study for its source and licence. Contact maps marked reprocessed were rebuilt by U-Chrom from the deposited read pairs.
